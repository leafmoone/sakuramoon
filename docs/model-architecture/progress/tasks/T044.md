## Contract

- Production raw state contains model, complete optimizer, trainer counters,
  scheduler/growth, rank training RNG, optimizer-SR RNG, resolved config and identity.
- Raw checkpoint state and API contain no `mainset`, shard cursor/order,
  active/completed/replay, cache/lease, prefetch/queue or opaque data sidecar.
- Legacy raw schema carrying `data_state.json` and any unknown raw sidecar fail before
  applying model, optimizer or RNG. Model-only/PMA/release v1 artifacts remain readable.
- Fresh-process next-update correctness uses one explicit fixed input batch and compares
  output, per-sample/mean loss, all gradients, clip coefficient, update, optimizer state
  and RNG. Live service batch continuity is explicitly outside this equality contract.
- A separate D024 client test proves resume leases the service's current cursor without
  sending or requesting a historical data position.

Implementation and review agents do not commit; the main agent performs final

## Implementation result

- Raw manifests and trainer/growth state documents use schema v2. Model-only,
  PMA and release artifacts remain schema v1.
- The raw API requires exact UTF-8 TOML resolved-config bytes whose SHA-256
  matches the checkpoint identity. Exact v2 raw sidecars contain no data state.
- Raw v1, legacy `data_state.json`, unknown sidecars (including payloads hidden
  under `model/`) and invalid or mismatched resolved config are rejected before
  model, optimizer or RNG mutation.
- PMA accepts only exact v2 raw inputs and still publishes a schema-v1,
  non-resumable inference artifact.
- Stage transition request, CLI and published plan no longer accept or carry the
  superseded data pass/seed controls.
- A real fixed-batch fresh-process test compares exact output, loss, all 239 FQN
  gradients, clip coefficient, update, optimizer state and both RNG streams.
- A real AF_UNIX client test proves a resumed trainer leases the service's current
  position without transmitting any historical data cursor.

Detailed implementation and test evidence is in `reviews/T044/`. Four-rank
restore, DDP/NCCL and formal stage evidence remain blocked.
