## Scope

- Count scheduler and periodic checkpoint cadence only from successful optimizer
  updates while retaining attempted-update and effective-sample counters.
- Accumulate exact per-sample sums, normalize once at the update boundary, perform
  the existing FP32 global finite/clip check, and poison every failed update.
- Stop on input, loss, backward, clip, optimizer, scheduler, or checkpoint failure;
  discard pending gradients and never mutate batch, accumulation, backend, world
  size, learning rate, or checkpoint cadence.
- Run every mandatory single-GPU preflight category in fixed order, reject missing
  or extra categories, stop at the first failure, and expose no force/bypass input.
- Atomically publish redacted failure bundles containing only exception type and
  update counters. Preserve both the training and publication error when diagnostics
  cannot be written.

## Evidence

- Targeted CPU tests cover golden accumulation/counters, nonfinite loss and gradient,
  partial-input/loss interruption, optimizer and post-update failures, diagnostic
  collision/symlink behavior, fixed preflight ordering, and report redaction.
- Package Ruff and strict Pyright pass.
- A bounded RTX 5090 smoke runs local Qwen and Mage-VAE, the 16-layer packed
  trainable composite, strict JLT loss, backward, FP32 clip, and one TorchAO update.
- An adjacent real AF_UNIX D024 service smoke drives two spawned persistent workers,
  durable RAW readback/retention, fresh-process restore-before-service, replay, and a
  next update without moving service/cache/state ownership into training. The final
  worker contract records exact worker IDs `{0,1}`, distinct child PIDs, and both
  leases before the fresh stream closes after update 2.
- Resolved S0 stage/growth/budget/cadence and attention-backend identities are bound
  during preflight and again at the training boundary. Failed preflight/report paths
  deterministically close the D025 stream and preserve simultaneous close failures.
- No training long run, DDP/NCCL path, automatic fallback, or model download ran.
