# M030: Global condition and modulation

Status: CPU/1GPU implementation and evidence remediation complete; Dense Model package rereview pending.

## Scope

- Embed FP32 `t`, target-canvas `size_scale`, and `aspect` as fixed 256/64/64-dimensional sinusoidal features.
- Produce FP32 `condition_hidden` through the locked `384 -> 1024 -> 1024` SiLU MLP.
- Produce six block modulation vectors with one shared projection plus stable-slot bias, with both paths zero-initialized.
- Keep the zero-initialized `condition_hidden -> SiLU -> 5120` final scale/shift projection independent from block modulation.

## Evidence

- `tests/unit/conditioning/test_global_condition.py`: 6 passed, including the explicit active-slot selection contract consumed by M031/M032.
- Packing/RoPE integration tests: 5 passed.
- Ruff and strict Pyright passed for the implementation and tests.
- RTX 5090 production-dimension FP32 forward/backward used `d=2560`, 24 stable slots and 16 active slots. Outputs were `[2,16,2560]` block tensors and `[2,2560]` final tensors with finite gradients.
- Hot forward was 0.531-0.627 ms, backward was 115.516 ms, and peak allocated memory was 301.2 MiB.
- The conditioner hot path performs no tensor-to-Python timestep range synchronization. Training/sampling entry points own value-range validation; the module still strictly rejects mismatched shape, dtype, device, and slot metadata.
- Remediation added nonzero positive/negative sinusoidal embedding goldens, exact target-canvas-to-384D-condition input goldens, CFG canvas equality, the locked six-chunk modulation order, and FP32-under-autocast coverage.
- `tests/unit/conditioning`: 38 passed. A fresh RTX 5090 production-dimension forward/backward used horizontal/vertical T024 canvas conditions `(0.5, +/-1.0)` with finite FP32 outputs and gradients; zero-initialized modulation remained zero.

No multi-GPU, DDP/NCCL, formal stage, or training long run was executed. Dense Model package review remains pending.
