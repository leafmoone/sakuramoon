## 动作

- 安装并锁定 uv，限定 Python 3.12 和 Linux。
- 依据真实 RTX 5090/CUDA 12.8 环境选择可解析的 PyTorch、TorchAO、Transformers、Diffusers、Safetensors、ModelScope、W&B、WebDataset、Pillow、einops、Pydantic、pytest、ruff 与 pyright 版本。
- FA4/CuTeDSL、Triton、`causal_conv1d`、`fla` 必须用明确版本或 Git SHA 表达；若当前兼容矩阵无法形成可重建锁，明确阻塞，不以可变 HEAD 或静默省略替代。
- 生成系统 driver/CUDA/NCCL/编译器报告、lock hash、依赖许可证清单和 fresh environment 重建证据；报告必须区分空 `.venv` 与空 uv cache。

## AI/Infra 自检

- 不引入训练参数或 dropout 值，不读取历史候选配置。
- 不把 import 当作 kernel 通过；真实 kernel 执行仍属于 `K001/T021/T040`。
- `uv sync --frozen` 必须从干净 `.venv` 重建；保留 uv cache 时必须明确标注 cache-warm，不得把它表述为源码冷重建，也不得用临时 pip 或系统 site-packages 补缺。
- 不读取或记录 `.env` 内容；锁文件、错误与报告不得含 token。

## 针对性验收

- `uv lock --check`
- `uv sync --frozen`
- `uv run python -c` 验证锁定包元数据与 CUDA 可见性；不宣称 kernel 通过。
- `uv run ruff check` 和 `uv run pyright` 仅在存在对应源码时执行。
- fresh-env report、lock SHA-256、许可证清单、tracked secret scan。

## 非目标与回滚

- 不执行 K001/Qwen/VAE/TorchAO kernel 正确性测试，不下载数据集，不实现 D001/C001/A001。
- 不执行或关闭任何多卡门槛。
- 实现代理不创建 commit；失败时保留诊断，不使用系统 pip、可变依赖或隐式 fallback。

硬件等级：CPU 环境锁 + 单卡可见性检查；不要求 GPU kernel。

## 实现结果

- `uv 0.12.0` 生成 Linux x86_64/Python 3.12 lock；最终 `uv.lock` SHA-256 为 `ee6a52d796e029a9a19db1e59011f8a801f3ea3b451f3a70b0190679dc2244ef`。
- 在保留项目 uv cache 的前提下，从空 `.venv` 执行 `uv sync --frozen` 并安装 94 个 distributions，sync 用时 24.81 秒；未下载或重新编译。该证据是 cache-warm fresh-venv 恢复。
- 随后使用独立空 uv cache 与空 venv 执行 frozen sync，94 个 distributions 在 2002.709 秒内安装完成，`causal-conv1d` 从固定 commit `4f6ae4e26ae5fe8af9372f8d312ab25cc4595223` 重新编译，22 个关键 imports 全部通过。开始/当前 `pyproject.toml` 的 canonical lock-input digest 均为 `7f10b80856f5e6d20b6637c416f753980a7347a3c3e64c601c289b0afb3035cf`，因此工具入口变更没有改变依赖解析输入。
- PyTorch `2.10.0+cu128`、TorchAO `0.16.0`、Transformers `5.14.1`、FA4 `4.0.0b24`、FLA `0.5.2`、Triton `3.6.0` 和数据/配置工具均已精确锁定。
