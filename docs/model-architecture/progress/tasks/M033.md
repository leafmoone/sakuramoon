# M033: Flow objective, CFG, and Heun sampler

Status: implementation and 1GPU integration complete; Dense Model package review pending.

## Scope

- Sample JLT timesteps with explicit `P_mean=-0.8` and `P_std=0.8`, and sample unit-scale noise from an explicit generator.
- Interpolate `z_t=t*x+(1-t)*epsilon`; the network predicts clean `x`.
- Convert x-prediction to velocity in FP32 with `max(1-t,0.05)` and reduce each sample before the batch mean.
- Convert conditional and unconditional x-predictions to velocities independently before CFG with scale 2.9.
- Run 50 intervals as 49 Heun updates plus one final Euler update for exactly 99 NFE, keeping solver state FP32 and disabling autograd inside the sampler.
- Keep value-range validation out of the per-NFE CFG hot path; the solver owns its `[0,1]` time grid and performs one final finite-state check.
