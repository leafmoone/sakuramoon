# D017: Regenerable image scan report publication

Status: implementation and targeted CPU validation complete; Data package rereview
pending. Implementation commit reference: `task:D017`.

## Dependencies

- D013 owns image scan semantics and canonical report bytes.
- G001 requires regenerable single-file image/metric reports to use a sibling
  temporary file, file fsync, and `os.replace`.

## Scope

- Replace the obsolete no-clobber hard-link protocol for the regenerable combined
  image scan report.
- Write canonical bytes to a unique sibling temporary file, flush and fsync that file,
  then atomically replace the destination with `os.replace`.
- Preserve an existing report if replacement fails and remove task-owned temporary
  files on every failure path.

## Non-goals

- No change to canonical report content, scan accounting, bucket selection, crop
  execution, or decoded-dimension thresholds.
- Retention quantiles are implemented separately by D018.
- No production metadata scan, 100,000-image decode scan, GPU run, benchmark, DDP,
  NCCL, multi-GPU, long run, or formal stage evidence is claimed.
