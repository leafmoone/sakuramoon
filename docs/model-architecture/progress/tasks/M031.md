# M031: Dense SDPA DiT primitives

Status: code and 1GPU validation complete; Dense Model package review pending.

## Scope

- Keep RMSNorm weights in FP32, accumulate normalization in FP32, and return the activation dtype.
- Implement bias-free fused-input SwiGLU with the locked `[gate, up]` split and intermediate size 6912.
- Implement dense SDPA reference attention with native 20-query/5-key-value heads, Q/K normalization before 2D RoPE, no V normalization, and no KV repeat.
- Apply the token-dependent sigmoid content gate before the output projection, and raw condition residual gates with external non-learned growth scalars.
- Mask both padding queries and keys and clear padding rows after each block.

## Evidence

- `tests/unit/model/test_primitives.py`: 9 passed; 11 M030/T024 regression tests also passed.
- Tests cover FP32 RMSNorm math, fused SwiGLU order, dense query/key masks, native GQA shapes and formula, content gating, padding isolation, raw residual gates, growth-zero identity, bias policy, and the exact production block parameter count.
- Ruff and strict Pyright passed for the new modules and tests.
- RTX 5090 BF16 production block used `[1,1540,2560]`, native 20Q/5KV, 76,027,136 parameters, finite forward/backward, and one successful parameter update.
- Hot inference forward was 4.363-4.526 ms, training forward 5.661 ms, backward 49.029 ms, update 13.717 ms, peak allocated 1166.4 MiB and peak reserved 1444.0 MiB.
- Masked dense SDPA selected the PyTorch math kernel. This is reference evidence only; K001 still owns FA4 production correctness and performance.
