# M032: Stable-slot DiT and image output head

Status: dense reference and packed FA4 production code have completed 1GPU validation; Dense Model package rereview pending.

## Scope

- Assemble 16/20/24-layer dense reference models with canonical final-position slot names.
- Insert G1 slots at 02/08/14/20 and G2 slots at 05/11/17/23 without renaming old parameters.
- Register only active block and per-slot bias parameters so future slots do not acquire optimizer state early.
- Project native 128-channel latent cells directly to hidden tokens, with no extra patchify.
- Read only the image span through conditional final RMSNorm and a zero-initialized FP32 `2560 -> 128` output projection.
- Keep dense SDPA explicit as a reference backend. The production model consumes T024 flat-varlen sequences through K001 FA4 directly; no packed-to-dense production adapter is introduced.

## Evidence

- `tests/unit/model/test_dit.py`: 5 passed; 55 targeted model/conditioning/config tests passed.
- Tests cover exact slot sets, stable old FQNs, absent future bias parameters, alpha-zero function equivalence, image-only shape, zero output, and model metadata.
- Production CPU parameter audit: 16L=1,239,766,144; 20L=1,543,936,128; 24L=1,848,106,112. Future G1/G2 parameters are absent until active.
- RTX 5090 full 24L BF16 dense small-sequence two-step validation passed. Step one produced exact zero output and updated the head; step two produced nonzero output and nonzero trunk/shared-modulation/final-modulation gradients.
- Full 24L allocated peak was 7,328.8 MiB and reserved peak 7,688.0 MiB. Cold/second forwards were 475.154/49.383 ms and backwards were 151.789/64.454 ms. These are engineering-reference timings, not production FA4 or 512 performance claims.
- Dense and packed 16L production models have identical state-dict names, shapes, and dtypes on the meta device.
- RTX 5090 packed tests passed for two unequal sample lengths, dense-reference block agreement, exact cross-sample isolation, heterogeneous image-span recovery, and 16L three-stage gradient startup: head first, then input/condition paths, then block matrices.
- A real 16L/256 packed forward/backward at 324 tokens peaked at 4,864.9 MiB allocated and 5,232 MiB reserved (2,421.1 MiB model/input baseline). Cold forward/backward wall time was 10.519 s including first CuTe compilation.
- A real 24L/512 packed no-grad smoke at the maximum 1,540-token sequence peaked at 3,766.6 MiB allocated and 3,930 MiB reserved (3,590.1 MiB baseline), returned finite `[128,32,32]`, and took 5.714 s cold. These cold values are capacity evidence, not steady training throughput.
