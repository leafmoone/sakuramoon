## Remediation contract

- Require one immutable D010 `ShardRecord` for every explicit absolute local shard
  path. Reject duplicate records, cardinality drift, and path/record suffix mismatch.
- Require an explicit D011 `MetadataFieldMapping`; there are no production field-name
  defaults.
- Require an explicit metadata adapter before D011 parsing so nested real-dataset
  fields can be projected without embedding schema defaults in the pipeline. The
  caption parser still receives the original unmodified JSON.
- Resolve every WebDataset sample's exact `__url__` to its trusted record and call
  `parse_shard_metadata(..., shard=record, fields=mapping)`. Unknown sources hard fail.
- In durable paths, recover the record only from the coordinator's manifest. Sample
  JSON cannot select or override `release`.
- Preserve the trusted release through `PipelineSample` and `TrainingBatch.releases`.

This task does not change D012 state or remove D015's one-worker durable guard. Those
changes remain separate D022 and D023 remediations.
