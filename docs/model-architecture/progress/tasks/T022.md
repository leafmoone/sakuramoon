# T022: Main text conditioner

Status: code and 1GPU BF16 validation complete; package review pending.

## Scope

- Gather only structured main-token indices from the seven frozen Qwen states.
- Apply seven independent FP32-accumulating RMSNorms, one shared input projection, and token-dependent 8-group layer mixing.
- Keep the deepest-layer anchor, one non-causal attention-only QK-normalized block, padding isolation, and final projection.
- Constructor requires the still-unlocked MHA/mix-gate/LayerScale choices explicitly; it does not invent runtime defaults.

## Evidence

- `tests/unit/conditioning/test_text_mixer.py`: 3 passed.
- Tests cover gather isolation, uniform initial layer weights, frozen-input gradient boundary, bidirectional dependence, and padding isolation.
- Package Ruff and strict Pyright passed.
- RTX 5090 BF16 forward/backward produced `[2,32,2560]`, kept padding zero,
  detached Qwen inputs, and produced finite gradients for all reached adapter parameters.
- With explicit smoke-only constructor choices, warm forward was 2.25-2.58 ms,
  backward was 2.31-2.66 ms, and peak allocated memory was 114.8 MiB.

The smoke-only head/init choices are not recorded as production defaults. They remain
explicit constructor inputs until the corresponding configuration decision is locked.
