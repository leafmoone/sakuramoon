## Scope

- Report accepted-crop retention P01/P50/P99 with deterministic nearest-rank semantics.
- Use a fixed 10,001-bin histogram over `[0,1]` at `1e-4` resolution so memory does not
  grow with manifest size and quantization error remains below `1e-4`.
- Emit explicit method/resolution metadata and `null` quantiles when every sample is
  rejected.
