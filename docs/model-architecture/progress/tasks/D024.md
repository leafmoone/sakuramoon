## Service contract

- One independently launched AF_UNIX service process exclusively owns ModelScope
  transport, download partials, byte/SHA verification, atomic shard publication,
  cache reservations/LRU/eviction, tar order, persistent status, and replay accounting.
- The service persists one full-manifest random `mainset` containing a random
  `mainset_id`, shuffle identity, exact ordinal permutation, per-row status, exact
  worker count, and replay counters. It rejects manifest, topology, permutation,
  ordinal, status-order, and schema drift.
- Trainer lifecycle inputs cannot affect data order. IPC identity contains only the
  immutable manifest digest and exact worker count; stage, pass, seed, run,
  checkpoint parent, cursor, snapshot, and resume data position are absent.
- The service re-prepares every recovered active row before scheduling pending
  lookahead. New activation is persisted before lease publication, and every active,
  ready, and in-flight path remains protected from eviction.
- Download concurrency, verified lookahead, lease/ACK capacity, per-worker input,
  ready batches, and completion output are all explicitly bounded. Deprecated
  `range_workers` is rejected rather than accepted without effect.
- Only normal DataLoader exhaustion produces an ACK. Worker exit, parent close,
  service kill, client disconnect, missing ACK, or publication failure leaves the row
  active for whole-shard replay. The final ACK rotates directly to a newly persisted
  full random mainset only when no outstanding lease, ready shard, or fetch remains.

## Independent review remediation

The first D010-D024 package review kept D010-D023 at PASS and found three blocking
D024 gaps. The service lock was derived from configurable `mainset_path`, a failed
concurrent socket binder could unlink the winner, and the recorded CUDA consumer used
an in-memory client. The remediation binds singleton ownership to the shared cache
root, acquires it before stale-socket handling/bind, and unlinks only a socket whose
inode matches this server's successful bind. CPU contracts cover distinct mainset
paths sharing one cache and simultaneous servers. The RTX 5090 contract now spawns a
real service process, uses the AF_UNIX client for every health/lease/ACK, drives two
persistent workers, moves all four batches to CUDA, ACKs the entire first mainset, and
observes atomic rotation. Detailed immutable evidence is in
`reviews/D024/remediation_report.md` and `remediation_test_report.json`.

The same independent DATA reviewer rereviewed `35e7e6f` and returned AI/Infra PASS for
the implemented scope. Immutable package rereview evidence is in
`reviews/DATA/d024_ai_rereview.md` and `d024_infra_rereview.md`; production manifest,
cold-cache, two-hour throughput, RSS/swap/quota, DDP/NCCL, long-run, and formal-stage
gates remain pending or blocked.
