## AI/模型正确性检查

- 根 README 与 AGENTS 明确现行决策优先级，禁止历史候选回流为配置。
- 明确所有训练参数后续只能来自 `config/*.toml`，不得使用代码隐式默认值。
- 明确单卡证据不能替代四卡门槛，未决 dropout 不得被编造。

## Infra/性能检查

- 初始化根 Git 仓库并建立最小、明确且可维护的 ignore 边界。
- `.env`、模型、DB、dataset/cache、reference 嵌套仓、checkpoint、W&B、profile 和训练 artifact 不得进入索引。
- 记录 `HDM`、`JLT`、`krea-2` 的 URL、精确 commit 与许可证；只记录元数据，不复制资产。
- tracked 文件不得包含凭据、私钥或模型/数据大文件；secret 扫描必须零命中。

## 验收命令与证据

- `git status --short --ignored`
- `git check-ignore -v` 覆盖 `.env`、三个模型/数据/参考路径和训练 artifact 示例。
- `git ls-files` 生成 tracked file manifest；不得包含忽略边界内路径或嵌套 `.git`。
- 对 tracked 文件运行本地 secret pattern 扫描，结果必须为零命中；扫描器不得读取 `.env`。
- 记录三份参考仓库的 remote、HEAD 和许可证文件摘要。
- 产出 `implementation_report.md`、`ai_review.md`、`infra_review.md`、`test_report.json`、`timing.json`、`artifacts.json`；本任务不属于性能任务，不生成性能证据占位。

## 回滚点

- 主代理提交前，R001 变更仅存在于新初始化仓库的工作树和索引；如验收失败，保留问题证据并由原实现代理修复，不删除或覆盖现有用户文件。
- 不使用 `git reset --hard`、`git checkout --` 或递归删除工作区。
