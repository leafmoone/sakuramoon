## 动作与验收

- 为现行条款分配稳定 ID，显式标记 superseded 历史项，建立 requirement→config→module→test→benchmark→artifact 映射。
- checker 双向验证现行 requirement 与关键模块/配置键；故意删除映射的负测试必须失败。
- 校验 archive SHA-256 不变，current 文档演进有 changelog。
- 实现摘要、针对性测试、耗时与 artifact 证据随 D001 单独提交；AI/Infra 在 Foundation 包末审查。

## 实现结果

- 三份 canonical current source 共登记 219 个规范节点；每条 requirement 直接保存 config、module、reference、test、benchmark、artifact 映射，不只依赖 profile 隐式继承。
- checker 固定 source/scope，验证稳定 locator、状态图、硬件门槛、真实 review/artifact、双向生产库存、archive checksum/symlink、current SHA changelog 和非 archive 文档链接。
- 32 个正负 contract 测试通过；Ruff、严格 Pyright 和独立 checker 均通过。GPU 未使用。
- 证据位于 `docs/model-architecture/reviews/D001/`；最终 AI/Infra 结论按 Foundation 包规则延后，不提前把 requirement 标为 verified。
