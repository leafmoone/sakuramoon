## Acceptance contract

- The public loader rejects every production entry while any explicit external or
  benchmark sentinel remains unresolved.
- Base plus eight stage overlays, eval, and sample cover the complete runtime schema;
  unknown, missing, wrong-type, out-of-range, or fixed-value drift hard-fails.
- S0/S1/G1/S2/G2/S3 preserve the approved topology sequence. H1/H2 are disabled
  `template` intents and cannot cross the training runtime boundary.
- Global batch and valid-sample budgets obey exact equations. Activation checkpoint
  modes are explicit and unsupported modes fail at the runtime boundary.
- Every Text, Style, DiT, RoPE, condition, and output-head constructor argument is
  derived from one validated config field. A meta-device construction round trip must
  reproduce the exact config-bound assembly document.
- Local metrics are opened durably before asynchronous upload work. W&B uses stable
  `run_id`, `resume="allow"`, bounded queues, replay-before-new-submission, and an
  explicit retry-only path for initialization outages.
- `timing.phases` must exactly equal the ordered 12 core plus 13 detailed T051
  vocabulary. Assembly rechecks that binding before remote or local construction.
- Replay communication failure retains the original queue and permits local startup;
  authentication, protocol, malformed, non-private, or unsafe failures remain fatal.
- Close order is observer, remote queue, managed remote run, then local sink, and all
  primary/cleanup errors remain observable.
