# T040: Mixed parameter precision and TorchAO AdamW8bit

Status: complete on one GPU; independent AI and Infra remediation rereviews passed.

## Scope

- Audit every trainable canonical FQN by owning module role. Linear/MHA projection matrices use BF16 with decay 0.01; norms, bias/scalar/1D parameters, condition/output-head parameters, text gates, modality/style/query/null embeddings use FP32 with no decay.
- Construct text/style projection matrices directly in BF16 while retaining their sensitive gates and learned tokens in FP32.
- Build one locked TorchAO AdamW8bit with `lr=2e-5`, betas `(0.9,0.95)`, epsilon `1e-8`, block size 256, and BF16 stochastic rounding. Reject BF16 decay matrices that would use TorchAO's non-quantized state fallback.
- Keep optimizer stochastic-rounding RNG isolated from the training CUDA RNG, validate restored RNG state at load, and preserve it with optimizer/schema state.
- Compute and apply one FP32 global gradient norm with clip threshold 1.0; reject non-finite gradients before state advances.

## One-GPU Evidence

- Full 16-layer `dit+text+style` audit: 239 FQNs, 126 BF16 decay matrices, 113 FP32 no-decay parameters, schema `16a0887eb1b638bb42e5780d3a759e66a82f476221fd311f1f0ff9037a7682a6`.
- Full lazy-state initialization: 152 quantized and 87 regular state entries, all 126 BF16 decay matrices using 256-block `OptimState8bit`; physical optimizer state 2,568,392,844 bytes.
- Held-out 1,000-step validation EMA ratio mixed/reference: 0.9995465; maximum over steps 501-1000: 0.9995641, below the 1.03 limit.
- Serialized optimizer/model/SR state restores to a bitwise-identical next update. Corrupt SR dtype/shape and non-finite gradients fail before optimizer state advances.
- Full affected suite: 35 passed on one RTX 5090; Ruff and strict Pyright passed.
