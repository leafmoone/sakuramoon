# T023: Artist style resampler

Status: CPU/1GPU implementation and host routing-plan remediation complete; T050 binding and Encoders package rereview pending.

## Scope

- Gather only structured Artist indices from the same seven-state Qwen output.
- Apply shared RMSNorm, learned layer embeddings, Artist-times-layer flattening, four-query cross-attention, residual SwiGLU, and output projection.
- Route missing Artist, Artist dropout, and all-condition dropout to four learned null style tokens.
- In mixed batches, gather, normalize, and project only samples that actually consume
  Artist conditioning. Masked positions and null-routed samples must not reach gather
  even when their placeholder indices are outside the Qwen sequence.
