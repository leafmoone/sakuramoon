## Contract

- The production ModelScope metadata adapter and caption parser are module-level,
  governed data APIs rather than helpers defined only by a GPU test. They preserve
  D021's trusted `ShardRecord`, explicit metadata mapping, original-JSON caption
  parsing, and D014 caption/image/collate semantics.
- The validation exclusion set is loaded from the configured JSONL only after exact
  SHA-256, 2,000-row cardinality, canonical field/type/encoding, sorted-ID, and
  global-uniqueness validation. Missing files, symlinks, digest drift, malformed
  rows, and identity drift hard fail before worker construction.
- `stage.local_batch`, `data.cache.persistent_workers_per_rank`,
  `data.cache.ready_batches_per_rank`, `data.loader.pin_memory`, and
  `data.loader.drop_last` are the only loader-control sources. The production loader
  accepts a resolved `RuntimeConfig`, rejects service topology drift, and exposes no
  independent value arguments or fallback topology.
- D024 continues to own network, download, verification, cache, `mainset`, lease,
  ACK, and replay state. D025 imports none of the service-owned transport/cache
  implementation and does not alter completion or restart semantics.
