# T024: Modality, packing, and 2D RoPE

Status: CPU/1GPU implementation and accepted-boundary remediation complete; the
independent Encoders package rereview returned PASS for the implemented scope.

## Scope

- Keep modality embedding, padding-free sequence packing, and RoPE as separate APIs.
- Pack `[valid text|4 style|image]` per sample and emit int32 `cu_seqlens`, spans, image shapes, and maximum sequence length.
- Use zero text/style coordinates and area-normalized image cell centers.
- Apply FP32-accumulating Q/K head normalization before shared-frequency `32/48/48` 2D RoPE without repeating KV heads.
- Expose target-canvas-only size/aspect scalars.
- Require text/style/image tokens to share one floating dtype and device, require mask
  colocation, and require Q/K/coordinates/frequencies to satisfy the locked dtype/device
  contract before arithmetic.
- Derive an immutable boundary handle from validated host-side sequence lengths when
  packing. Reuse it through PackedDiT/FA4 without reading CUDA boundaries back to CPU.
- Accept host-validated contiguous text lengths from collate/composite, verify the CUDA
  mask with a fixed-shape device predicate, and slice static prefixes instead of using
  CUDA boolean advanced indexing.
- Construct `ValidatedCuSeqlens` only from host lengths and reject inconsistent static
  tensor/host metadata before importing or calling the native FA4 kernel.
- At the packed-model entry, compare the untrusted public CUDA offsets with the
  canonical host lengths exactly once, then rematerialize a private accepted
  capability. Derive sample routing and every block's FA4 offsets from that same host
  identity; never perform a per-block D2H check.

## Evidence

- Tests cover order, padding removal, sample isolation, coordinate goldens, Q/K ordering, KV head preservation, and size/aspect math.

  promotion rejection, and boundary construction that is valid by construction.
