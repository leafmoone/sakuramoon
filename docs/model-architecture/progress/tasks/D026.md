## Contract

- The only accepted storage mode is explicit `server_backed`; it never infers media
  identity from a directory name or silently falls back to local storage.
- Persistent run, cache, checkpoint, artifact, and mainset paths must resolve to the
  configured NFS filesystem, exact source, NFS version, and hard-mount identity.
- Cache low/high watermarks are explicit and bounded but have no 300 GiB minimum.
  Capacity must cover the configured high watermark, three measured raw checkpoints,
  and an explicit free-space reserve on each distinct persistent mount.
- Startup probes same-directory write, file fsync, replace, directory fsync, and
  readback semantics. Probe residue is removed precisely on success and failure.
- AF_UNIX socket and singleton ownership lock are fixed host-local paths under
  `/run/sakuramoon`; they must not resolve to NFS. Persistent state remains on NFS.
- Identity, capacity, atomic-publication, socket, or ownership drift is a hard failure
  with no force flag or bypass.

## Non-goals

D026 does not change D022/D023 shard state, D024 mainset/lease semantics, D025 trusted
batch assembly, checkpoint schemas, training batch size, backend, world size, or
multi-GPU gates. It does not run a long benchmark or formal stage.

## Evidence

- Strict server-backed schema accepts explicit small cache watermarks and rejects
  missing/unknown/drifted mode, filesystem, source, NFS version, hard mount,
  checkpoint copies, atomic probe, socket, and ownership fields.
- The production data-service CLI invokes governed storage validation before manifest,
  credential, or network work. T050 preflight invokes it with the measured raw
  checkpoint payload and has no NVMe inference check or force path.
- DataSupplyService now requires an explicit absolute ownership lock outside the
  shared cache. Production binds it and AF_UNIX to fixed `/run/sakuramoon` paths;
  singleton, concurrent-server, restart, ACK, and replay regressions remain green.
- Current NFSv3 identity and hard-mount checks passed for the exact configured source.
  Same-directory write/file-fsync/replace/directory-fsync/readback passed with no
  residue. The mount had 383,347,851,264 free bytes; three copies of the previously
  measured 5,143,055,405-byte raw checkpoint require 15,429,166,215 bytes, leaving
  367,918,685,049 bytes before the still-explicit cache and reserve budgets.
- Targeted config/storage/service/preflight/fault selector: 52 passed. Full config
  regression: 129 passed. Ruff passed; strict Pyright reported 0 errors/warnings.
  Trace contracts passed 40/40 and live trace passed 237/237 nodes.

Production cache high-watermark/concurrency remains benchmark-configured with no
default. Two-hour cold-cache throughput, ready wait, RSS/swap, formal stage, DDP/NCCL,
