## Scope

- Load only `model/qwen_3.5_2B` with local-files-only and no fallback.
- Instantiate `Qwen3_5ForCausalLM` from the text config, retain only its text model, and never build or call a visual path.
- Freeze eval/inference execution, force `use_cache=false`, and select after blocks `2/4/8/12/16/20/24` from one forward.
- Capture decoder block 24's raw return with a temporary hook in that same forward.
  Do not use Transformers 5.14.1's replaced `hidden_states[-1]`, which is final-RMSNorm
  output, and do not issue a second Qwen forward.
- Require `attention_mask` to be `torch.bool`, with `True` meaning a valid token. Reject
  every integer or floating mask before the backend forward instead of coercing values
  such as `2` or `-1` to true.
