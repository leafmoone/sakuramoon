## Scope

- Iterate only locally prepared D010/D012 shard paths through WebDataset; no dataset
  pre-download, model download, remote fallback, or `reference/` code path.
- Exclude validation IDs after one JSON parse and before caption/image processing.
- Decode one image, apply D013 EXIF/RGB/no-upscale bucket/crop, build one D014
  structured caption, and retain explicit audit and stage/pass/sample RNG identity.
- Group only identical image and Qwen dense buckets, pad with masked EOT, preserve
  structured main/Artist indices, and emit typed uint8 CPU batches.
- Require explicit persistent worker and ready-batch counts. The ready budget must
  divide exactly across workers; no silent queue-size adjustment is allowed.
- Keep only incomplete bucket fragments smaller than one batch. No text embedding,
  latent, activation, or cross-batch model cache exists.

The real dataset-to-`CaptionFields` mapping is an explicit callback because the
current documents do not define its raw field names. Production construction remains
blocked until that mapping and the eleven unresolved dropout probabilities are fixed.

The Data package audit found that D013 no-upscale and retention rejections escaped the
iterator. The pipeline now treats only typed `ImageRejected` outcomes as skipped
samples; decode, metadata, caption, tokenizer, and other contract failures still hard
fail. Real-tar tests prove both rejection reasons and continued iteration.
