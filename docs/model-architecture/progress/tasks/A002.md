## 第四轮 D010 HTTPS 接口收敛

- 精确允许路径只有 `src/sakuramoon/data/modelscope.py`、类 `ModelScopeDatasetTransport` 以及冻结 helper/factory 调用图；同形网络调用移动到其他文件、类或方法会失败。
- `target` provenance 必须来自 `_listing_target`、`_shard_target` 或 `_redirect_target`，公共入口必须先经 `require_verified_dataset_manifest`。首站固定 ModelScope HTTPS 端点；redirect target 只保留受审计 host/port/request-target/auth 形态。
- `headers` 必须来自固定 `_request_headers(target)`：固定 Accept、identity encoding 与 User-Agent；Authorization/Cookie 只在 `target.send_authorization` 时产生。`_open_get` 只允许追加精确 manifest-offset `Range`，任意参数映射、`update` 或重写均拒绝。
- 网络构造只允许 `http.client.HTTPSConnection(host=target.host, port=target.port, timeout=self._policy.connect_timeout_seconds, context=ssl.create_default_context())`；请求只能为固定 `GET`、`target.request_target`、空 body、审计 headers、`encode_chunked=False`。changed receiver、method alias、位置参数、关键字或 `**kwargs` 均拒绝。
- 响应访问只允许冻结位置中的 `Location`/`Content-Length`/`Content-Encoding`/`Content-Range`、`response.read(length)` 与明确 cleanup；SDK、HubApi、alternate HTTP/socket/logging/patching、TLS verification mutation 无例外。
