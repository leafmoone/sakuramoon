## Scope

- Define one fixed numeric record for every required loss, gradient, LR, timestep,
  batch, token, FLOP, memory, queue, nonfinite, dropout-hit, and phase-timing field.
- Append local JSONL before remote submission, fsync at the explicit record cadence,
  and fsync the containing directory when the file is created.
- Submit W&B-compatible numeric mappings asynchronously. Network failures write a
  redacted, fsynced retry queue and never mutate training/checkpoint controls.
- Replay the complete retry queue at startup with at-least-once semantics; retain the
  original queue byte-for-byte if replay fails.
- Use monotonic time on CPU and queryable CUDA events on GPU without synchronizing at
  phase boundaries. Provide balanced optional NVTX ranges.
- Convert T050's detached successful-update observation asynchronously after all CUDA
  events become queryable. FLOPs, samples/s, queue depth, and supplemental phase
  facts remain explicit assembly inputs rather than inferred values.

## Evidence

- 34 targeted CPU tests cover the fixed v2 schema, T050 observation aggregation,
  clip-norm consistency, bounded asynchronous publication/event timeout, accepted
  queue draining after the first failure, local-first ordering, fsync close,
  symlink/mode rejection (including private retry files before parsing), redaction,
  network failure/replay, CPU timing, and balanced NVTX.
- One real RTX 5090 CUDA-event test passed.
- A short real-GPU 1024x1024 matmul benchmark measured 0.8057% median overhead for
  one CUDA event range per operation, below the locked 1% threshold.

The benchmark is a focused historical instrumentation measurement, not a training
throughput claim. S0 now binds the explicit context provider, durable paths/cadence,
W&B run settings and lifecycle close order. Local metrics append before remote upload
and S0 uses `flush_every_updates=1`. The one-update capacity cells and two-update resume
run confirm production telemetry plumbing but do not establish steady-state overhead.
Four-GPU timing/DDP overhead remains blocked.
