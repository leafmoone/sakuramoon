## Scope

- Define one fixed numeric record for every required loss, gradient, LR, timestep,
  batch, token, FLOP, memory, queue, nonfinite, dropout-hit, and phase-timing field.
- Append local JSONL before remote submission, fsync at the explicit record cadence,
  and fsync the containing directory when the file is created.
- Submit W&B-compatible numeric mappings asynchronously. Network failures write a
  redacted, fsynced retry queue and never mutate training/checkpoint controls.
- Replay the complete retry queue at startup with at-least-once semantics; retain the
  original queue byte-for-byte if replay fails.
- Use monotonic time on CPU and queryable CUDA events on GPU without synchronizing at
  phase boundaries. Provide balanced optional NVTX ranges.

## Evidence

- 14 targeted CPU tests cover strict schema, local-first ordering, fsync close,
  symlink rejection, redaction, network failure/replay, CPU timing, and NVTX balance.
- One real RTX 5090 CUDA-event test passed.
- A short real-GPU 1024x1024 matmul benchmark measured 0.8057% median overhead for
  one CUDA event range per operation, below the locked 1% threshold.

The benchmark is a focused instrumentation measurement, not a training throughput
claim. Four-GPU timing/DDP overhead, full-chain per-phase coverage, and package-level
independent AI/Infra review remain pending/blocked.
