## 2. 本分支完成的内容

### 2.1 `scripts/audit_training_metrics.py`

只读审计一个 metrics JSONL 窗口，回答三个容易混淆的问题：

- 窗口内存在哪些 update；
- 哪些遥测行缺失（输出为连续区间，不物化每个整数）；
- 哪些行字节相同、哪些同 update 同 payload、哪些内容冲突。

关键口径：

- 重复检测忽略 `recorded_at_unix_ns`，因为生产者每次重写都会换时间戳；
- 缺失只表述为“遥测缺口”，不推断该 update 未执行；
- 统计按 update 去重（同一 update 取最后一条），同时报告 `source_rows`；
- loss 字段回退到 `total_loss` 时记录 `loss_field_used` 与 `loss_fallback`；
- NaN/Inf 不进入统计，计入 `invalid_numeric_values`；
- `--out` 不允许指向输入文件；截断的 `.jsonl.gz` 记录 `container_error` 而不崩溃。

### 2.2 `scripts/check_configs.py`

解析 `config/**/*.toml` 的 `extends` 图：

- 缺失父节点、重复条目、绝对路径、环均报错；
- `config/external-parents.toml` 声明部署专用父配置，键必须是**根相对路径**；
- 目录形式的 `*.toml` 被忽略；
- 仅遍历本 checkout 内可解析的边；经外部/缺失父节点的环不可见（已在 `notes` 说明）。

### 2.3 `.github/workflows/ci.yml`

- static：`ruff` + 仅对**变更的 Python 文件**跑 `pyright`（仓库既有基线约 4,121 条错误，不作为本分支门禁）；
- unit：Python 3.12（仓库 `.python-version`）、CPU torch、两个新增测试文件；
- contracts：逐文件 `bash -n`、配置继承图、`gitleaks-action@v3`（关闭 PR 评论，个人账号无需 license）；
- 所有 job 使用 `checkout@v6` 与 `setup-uv@v10.3.0`（上游无 `v10` 浮动主标签，必须 pin 具体版本），`uv run --no-sync` 避免隐式解析完整依赖；
