# anime-sr 主设计：如何训出一个优秀的 anime 放大模型

> 状态：讨论稿（v1，2026-08-26）。依据：10 篇精读（一梯队 3 + 二梯队 6 + Mage-Flow 本体）
> + M0 bake-off 实测（PASS）。代码实现（M2）以本文档为蓝图。

## 1. 十篇论文各贡献了什么（一句话）

| 论文 | 核心发现 | 我们拿走什么 |
|---|---|---|
| **RFMSR**（一） | LQ-centered 源分布 N(y_lq, σ²I) 的残差流匹配：预测"残差速度场"比预测绝对场平滑得多，天然支持 1-step | **主干算法**：两阶段 flow matching，σ=0.1 |
| **HiTokSR**（一） | DWT 小波域层级监督（可开关）：低频保内容、高频保纹理，粗到细分组 | **损失项**：L_DWT 防"平滑作弊"，直接治 M0 发现的 ≤4px 风险区 |
| **GAN-Diff**（一） | GAN 项挂在不稳定风险最低的时点（蒸馏后）、渐进 λ + R1/R2 稳定对抗 | **锐化配方**：RpGAN 接法 |
| **SeedVR2**（二） | 蒸馏 ~10K 步/阶段即可 1-step 化；对抗后训练 RpGAN λ0.15 + 特征匹配 layers[8,16,24] λ0.1 + R1/R2 0.01 | **Phase II 全套超参**，直接复用 |
| **TEASR**（二） | SAD 空间自适应蒸馏：20B 模型仅 2×A100/47K 步完成蒸馏 → **蒸馏便宜，贵在 Phase I 教师** | 算力预算原则：MVP 300K 够用，别过度堆 Phase I |
| **FSP-Diff**（二） | 1-step 推理 0.15s@512² | 速度目标锚点（我们 0.5–1.5s@2048² 同量级） |
| **Transfer VAE**（二） | 4× VAE 比 16× 高 +7dB（PSNR 25.29→32.35）；8× 即丢不可逆高频 | M0 门的动机（已实测排除：Mage-VAE 128ch 容量够） |
| **Mage-Flow 本体** | Mage-VAE：128ch/16× 一步扩散 codec、无全局注意力（MAC 较 FLUX.2 低 12–22×）、anchor-latent KL、任意长宽比 512–2048 | **冻结的 latent 空间**（M0 实测：1px 线无损、0.135s@1024²） |
| **FoA-SR**（二） | "Faithful" 画像 = 保真-锐度权衡是**配置问题不是架构问题**；LoRA rank64 β1000 控内容漂移 | **保真档位**：训练权重配置 + 内容漂移检查 |
| **DINO-HS**（二） | DINOv2 幻觉分 2.99→3.87 可量化漂移；HS≤3.5 可作守门 | **checkpoint 选择守门**（M3） |

## 2. 架构：唯一合理的组合（anime 域）

```
LQ 图 (256²/512²) ──退化──> ┐
                            ├─> Mage-VAE enc (冻结, 一步) ─> z_lq [B,128, h/16, w/16]
HR 图 (1024²/2048²) ────────> Mage-VAE enc (冻结) ─> z_hr  (训练目标)
                            └─> RFMSR 主干 (DiT 风格, 可训 0.3–0.5B):
                                z_lq 2×2 patchify → N 个 token (1024² 时 1024 tokens)
                                u_θ(x_t, t | z_lq)  预测残差速度场 → z_hr
                            ─> Mage-VAE dec (冻结, 一步) → 输出图
```

四个关键决策及理由：
1. **latent 域生成（不像素域）**：16× 下采样后主干只需处理 1024 tokens@1024²，算力降 256×；
   Mage-VAE 一步编解码（0.135s@1024²、1GB 显存，M0 实测）使 VAE 不再是循环瓶颈。
2. **RFMSR 而非像素 GAN/扩散**：残差流匹配在 anime 域有直接证据（一梯队）；
   LQ-centered 源分布让 1-step Euler 就是推理，不需要采样步数-质量权衡。
3. **冻结 VAE，只训主干**：VAE 质量已被 M0 验证（线宽比 1.0）；冻结使训练显存/算力
   全归主干，且推理端只需 1 次 enc + 主干 + 1 次 dec。
4. **DWT 层级监督（可开关）+ 对抗锐化（Phase II）**：分别解决"高频被抹平"与"不够锐"，
   且都不动主干结构 → 消融干净（M3 直接开/关对比）。

## 3. 训练配方：两阶段 + 1-step + 守门

| 阶段 | 时长 | 内容 | 损失 |
|---|---|---|---|
| **Phase I（教师级）** | MVP 300K iters（全量 500K） | 多步 flow matching，lr 1e-4，cosine decay | L_FM（按 t 加权）+ λ_dwt·L_DWT（粗到细）+ 10% 干净对（无退化，保真锚定） |
| **Phase II（锐化+守门）** | 50K iters | SeedVR2 式对抗后训练（主干冻结或部分解冻） | + RpGAN λ0.15（渐进升）+ 特征匹配 layers[8,16,24] λ0.1 + R1/R2 0.01 + LPIPS |
| **1-step 化** | 蒸馏 ~10K（TEASR 经验：便宜） | 单步 Euler 输出对齐 Phase I 教师输出 | L_1-step + 少量 GAN 保持 |

**数据**：MVP 200k anime 图（全量 1M）→ 预编码 (z_hr, z_lq) 对（200k ≈ 1.1TB bf16 latent）。
退化配方（×4 场景，每图 4 变体 + 10% 干净对）：
- 下采样：area/bicubic 混合（0.5/0.3/0.2 权重）
- 模糊：Gaussian σ∈[0, 0.8] 对数均匀
- JPEG：q∈[50, 95] 均匀
- 噪声：σ∈[0, 3]
- 评测集：100 张留出图（含 M0 合成线稿 + 真实 crop），**训练集绝不碰**。

**守门（M3）**：DINO-HS ≤ 3.5 硬门槛；内容漂移（LPIPS 下限 + DINO 语义差）；
FoA-SR 式"Faithful 档"（损失权重配置，非独立模型）。checkpoint 按 (PSNR, LPIPS, HS) Pareto 选。

## 4. 算力需求（工程口径）

| 项 | MVP | 全量 |
|---|---|---|
| 主干规模 | 0.3B（dim1024/depth24/heads16） | 0.5B（dim1280/depth30） |
| 训练分辨率 | 1024²（1024 tokens） | 2048²（4096 tokens） |
| Phase I | 300K iters | 500K iters |
| 单 iter 成本 | B=64, ~1.5s@8×A100 | B=64, ~4.5s@8×A100（实测折算） |
| **总训练量** | **400–800 A100-GPU·h**（8 卡 2–4 天） | **4–8K A100-GPU·h**（8×H100 3–4 周 / 8×B200 2–3 周） |
| 数据预编码 | 200k 图 ≈ 数天（4060 本地可先跑 1k 验证） | 1M 图 ≈ 1–2 周（8×A100） |
| 1-step 推理 | 0.3B@1024²：~0.3–0.8s @A100，显存 3–4GB | 0.5B@2048²：0.5–1.5s @A100，显存 4–6GB |

注：DTK/HIP 目标机若 MFU<30% 需按实测吞吐重折算（先用 100 iter 基准跑测）。

| 维度 | 指标 | 目标 |
|---|---|---|
| 保真 | DINO-HS | ≤3.5（无幻觉内容） |
| 保真 | PSNR @4×（anime 评测集） | ≥ 28dB（MVP 30dB+） |
| 锐度 | 1px 线宽保持率 / LPIPS | 线宽比 ≥0.95（M0 VAE 端 1.0）；LPIPS ≤0.05 |
| 锐度 | 主观 A/B（anime 线稿集） | 优于 Real-ESRGAN v2 + SwinIR-L |

| 鲁棒 | 长宽比 | 512–2048 任意（Mage-VAE 原生） |

## 7. 风险与兜底（每条都有预案）

| 风险 | 证据 | 预案 |
|---|---|---|
| ≤4px 致密排线丢高频 | M0：4px 网格 SSIM 0.69 | L_DWT + GAN 锐化；不够则微调 VAE decoder（一步 codec 微调，数天量级） |
| Phase I 欠拟合 | TEASR：贵在 Phase I | MVP 300K 是下限，看 DINO 语义漂移曲线决定加不加 |
| GAN 不稳定 | 常见 | 渐进 λ + R1/R2 0.01 + 特征匹配（SeedVR2 配方已验证） |
| 幻觉内容 | DINO-HS 2.99→3.87 会漂 | HS≤3.5 硬门槛进 checkpoint 选择 + 10% 干净对保真锚定 |
| VAE 选型翻车 | M0 已 PASS | 兜底 TVT 4× 迁移 VAE（免重训主干，latent 接口兼容层） |

## 8. 分辨率模式：通用架构 + 两阶段训练

- **架构通用**：Mage-VAE 原生 512–2048 任意长宽比；主干用 2D RoPE（对 token 网格尺寸不变）
  → 推理端任意尺寸/比例在范围内直接用，无需为新比例重训。
- **训练分两档**（算力原因，token 数是主成本）：
  1. **MVP：256²→1024²（×4，0.06MP→1MP，0.3B）** = "256 放大 1M"；
  2. **扩展：1024²→2048²（×4，1MP→4MP，0.5B）** = "1M 放大 4M"，从 MVP 权重短训 50–100K iters（4096 tokens）。
- ×4 比例写进退化管线；需要 ×2/×8 只换退化配方，模型不变。
- 利：一个模型覆盖两档 + 通用比例；弊：2048 档单 iter 4× 算力，通用模型在极端分辨率上是折中。
