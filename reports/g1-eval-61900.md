# G1 post-ramp baseline evaluation — update 61900

One-off standalone evaluation of checkpoint `ckpt_61900` on the src
machine, produced by the new `sakuramoon.cli.evaluate` entry point.
This is the single "G1 post-ramp baseline" reading: the 60000 online
evaluation never fired (restart skipped the `update % 5000 == 0` counter),
and the 59000/61000/62000 checkpoints were evicted (rolling slots=2), so
61900 is the available post-ramp reference. All downstream comparisons
(S0-vs-G1 at 65k, pre-70k concept benchmark) are read against this
baseline.

## Protocol

| | |
|---|---|
| checkpoint | `output_model/g1/ckpt_61900_raw-61900-update-cadence` |
| machine / env | src, DTK 26.04, `HIP_VISIBLE_DEVICES=0` |
| generated samples | 1000 (preview sampling profile) |
| real reference | `s0-validation-50k-v1`, 34,849 images |
| FID | 1000×1000, Inception feature space, full real set |
| KID | 100 subsets × 1000, seed 188978622924 |
| CMMD | CLIP `openai/clip-vit-large-patch14-336` |
